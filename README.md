# ⚡ AI CHALLENGE — БОТ «AI VS МОЛОДЁЖЬ»

> **«ИИ может дать ответ. Но сможешь ли ты превзойти его?»**  
> *«Think smarter. Create better. Challenge AI.»*

Полноценный интерактивный цифровой Telegram-бот на стыке EdTech, геймификации и соревновательного AI-тестирования. Бот превращает освоение искусственного интеллекта в увлекательную дуэль между человеком и нейросетью.

---

## 🌟 Ключевая концепция и игровые форматы

В отличие от классических ботов с пассивными опросами, **AI Challenge** обучает критическому анализу и взаимодействию с генеративным ИИ через три уникальных боевых формата:

1. ⚔️ **Human First (Ответь первым):**  
   Пользователь решает сложную нестандартную или логическую задачу сам, затем система генерирует ответ ИИ и сталкивает их в дуэли.
2. 🕵️ **AI Detective (Найди ошибку / Детектив галлюцинаций):**  
   ИИ предлагает ответ, содержащий скрытую фактическую, логическую или смысловую ловушку. Задача участника — обнаружить подвох и разоблачить нейросеть.
3. 🤝 **Co-Creation (Совместное улучшение):**  
   ИИ выдает поверхностный шаблонный драфт. Пользователь прокачивает ответ, добавляя критическую оценку, глубину и креатив.
4. 🧠 **Ежедневный вызов (Daily Challenge):**  
   Каждые сутки в 09:00 бот генерирует новый вызов. За непрерывную серию побед (Streak) начисляются мощные множители XP (до +50%).

## 🎮 Геймификация и экономика опыта

- **5 Рангов мастерства:**
  - 🌱 **Уровень 1: Новичок** (0–100 XP)
  - 🔍 **Уровень 2: Исследователь** (100–300 XP)
  - ⚡ **Уровень 3: Практик** (300–700 XP)
  - 🚀 **Уровень 4: Эксперт** (700–1500 XP)
  - 🧠 **Уровень 5: Сверхразум** (1500+ XP)
- **Система достижений:** Автоматическая выдача достижений (Первая победа, Серия 7 дней, Мастер промптов, AI Детектив и др.).
- **Таблица лидеров:** Прозрачный рейтинг лучших игроков с поддержкой приватности и отображением позиции пользователя.
- **Серверная безопасность:** Все начисления XP, прогресс и проверка условий строго изолированы на бэкенде.

## 🚀 Инструкция по запуску

### Вариант 1: Запуск через Docker Compose (Рекомендуемый)

1. Клонируйте проект и скопируйте конфигурацию:
   ```bash
   cp .env.example .env
   ```
2. Откройте `.env` и укажите ваш токен Telegram (`BOT_TOKEN`).
3. Запустите инфраструктуру одной командой:
   ```bash
   docker-compose up -d --build
   ```
   *База данных инициализируется и автоматически заполнится начальным контентом заданий.*

---

### Вариант 2: Локальный запуск (Python 3.12+)

1. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate
   ```

2. **Установите зависимости:**
   ```bash
   pip install -e .
   ```

3. **Настройте `.env`:**
   ```bash
   cp .env.example .env
   # Укажите BOT_TOKEN
   ```
   *Примечание: Если PostgreSQL не развернут, в `DATABASE_URL` можно указать локальный SQLite:*
   ```ini
   DATABASE_URL=sqlite+aiosqlite:///ai_challenge.db
   ```

4. **Запустите бота:**
   ```bash
   python -m app.main
   ```

## ⚙️ Переменные окружения (`.env`)

| Переменная | Описание | Значение по умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) | *Обязательно* |
| `ADMIN_IDS` | Telegram ID администраторов (через запятую) | `[]` |
| `DATABASE_URL` | URL подключения к базе данных (Postgres/SQLite) | `postgresql+asyncpg://...` |
| `REDIS_URL` | URL подключения к Redis для FSM | `redis://localhost:6379/0` |
| `AI_PROVIDER` | Режим AI: `mock`, `openai`, `openai_compatible` | `mock` |
| `AI_API_KEY` | Ключ OpenAI API (или совместимого провайдера) | `""` |
| `AI_API_BASE_URL`| Базовый URL API для LLM | `https://api.openai.com/v1` |
| `AI_MODEL` | Название языковой модели | `gpt-4o-mini` |
| `DAILY_CHALLENGE_HOUR` | Час ежедневной смены задания (0-23) | `9` |
| `DAILY_CHALLENGE_TZ` | Часовой пояс планировщика | `Asia/Almaty` |
| `MAX_REQUESTS_PER_MINUTE` | Лимит запросов от пользователя (анти-спам) | `30` |

## 🧪 Тестирование

Проект покрыт автоматическими тестами с использованием `pytest`:

```bash
pytest -v
```

Тестовый набор проверяет:
- Корректность формул XP, множителей сложности и серий.
- Переходы между уровнями и расчет прогресс-баров.
- Работу автономного Mock AI провайдера и санитизацию ввода.
- Обработку условий выдачи игровых достижений.
- Устойчивость к сбоям внешних API с автоматическим переходом на fallback.

## 🔐 Безопасность и защита от злоупотреблений

- **Prompt Injection Defense:** Все пользовательские текстовые ответы очищаются от системных инструкций и ограничиваются по длине перед передачей в LLM.
- **Rate Limiting Middleware:** Встроенный скользящий счетчик блокирует спам и флуд-атаки на команды бота.
- **Server-Side Progress:** Пользователь не может подделать XP или победу через клиент Telegram.
- **Privacy First:** Поддержка скрытия своего профиля из таблицы лидеров или использование игрового псевдонима.
